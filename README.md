
# Executive Sales Dashboard | Power BI

## Project Overview
This project focuses on analyzing sales data and building an interactive Executive Sales Dashboard using Microsoft Power BI.

The dashboard provides insights into revenue, gross profit, gross margin, quantity sold, orders, country performance, product categories, and sales channels.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Calendar Table
- Data Visualization

## Key KPIs
- Total Revenue: 645.22K
- Total Gross Profit: 296.38K
- Gross Margin: 45.94%
- Total Quantity: 6,698
- Total Orders: 2,707

## Key Insights
- The United Kingdom generated the highest revenue.
- Germany, France, Italy, and Spain were among the top-performing countries.
- Belgium, Switzerland, Finland, Czechia, and Ireland appeared among the bottom five countries by revenue.
- Monthly revenue and gross profit trends were analyzed.
- Product category and sales channel performance were compared.

## Skills Applied
- Data cleaning and transformation
- Data modeling and relationships
- Calendar table creation
- DAX measures
- KPI development
- Interactive dashboard design
- Business insights and reporting
